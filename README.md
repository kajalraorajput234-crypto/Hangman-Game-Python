# Hangman Game

## Description
This is a simple text-based Hangman game developed in Python.

## Features
- Uses 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Console-based gameplay
- Input validation

## Concepts Used
- Python
- Random Module
- While Loop
- If-Else
- Strings
- Lists

## How to Run
1. Install Python.
2. Save the code as `hangman.py`.
3. Open terminal or command prompt.
4. Run:

python hangman.py
